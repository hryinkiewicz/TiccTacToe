Руководство пользователя

Данная игра "Крестики - нолики " является увлекательной и интересной игрой для пользователей всех возрастов!

Цель игры заключается в том ,чтобы выстроить три своих символа (Х или О) в ряд по диагонали, горизонтали или вертикали.

Игровое поле состоит из 9 клеток, расположенных 3х3.

Игроки ходят по очереди. Чтобы сделать ход, нажмите на любую из свободных клеток.
